# EquationOne

EquationOne is an interactive mathematical and physics laboratory. This
initial application provides a React, TypeScript, and Vite foundation with
client-side routes for its main areas.

## Development

```sh
npm install
npm run dev
```

Run `npm run build` to type-check and build the application.

## Structure

- `src/app` contains application-level routing.
- `src/layouts` contains shared page layouts.
- `src/pages` contains route-level pages.

The physics, mathematics, numerical, and rendering engines are not implemented
yet.
